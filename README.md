# tallyrest

Tally identifiers and rest tokens for idempotent workflows.

**Site:** https://theworker02.github.io/tallyrest/

## Install / run

```bash
git clone https://github.com/theworker02/tallyrest.git
cd tallyrest
node src/cli.js
node --test
```
